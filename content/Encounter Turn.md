Each [[Turn]] character has:

- 3 Actions
- Reaction
- Free Action
- Movement

| Offensive Action           | Duration      | Description                                          |
| -------------------------- | ------------- | ---------------------------------------------------- |
| [[Weapon Attack]]          | [[Double Action]] | Make an attack with a weapon or unarmed strike.      |
| [[Off-hand Weapon Attack]] | [[Action]]    | Attack with a different weapon or hand.              |
| [[Disarm]]                 | [[Double Action]] | Attempt to knock an item from a creature’s grasp.    |
| [[Grapple]]                | [[Double Action]] | Attempt to put a creature to [[Grappled]] condition. |
| [[Shove]]                  | [[Double Action]] | Push a creature 1m. You may move with it.            |
| [[Trip]]                   | [[Double Action]] | Attempt to knock a creature [[Prone]].               |

| Defensive Action           | Duration      | Description                                                |
| -------------------------- | ------------- | ---------------------------------------------------------- |
| [[Dodge]]                  | [[Double Action]] | Gain +5 to your [[Evasion Class]] until the start of your next turn. |
| [[Raise A Shield]]         | [[Action]]    | Gain +2 to your [[Armour Class]] until the start of your next turn.  |

| Magical Action     | Duration                                | Description                                                  |
| ------------------ | --------------------------------------- | ------------------------------------------------------------ |
| [[Cast Spell]]   | [[Reaction]] or 1–3 [[Action\|Actions]] | Cast a spell.                                                |
| [[Identify Spell]] | [[Action]]                              | Make an [[Arcana]] [[Check]] to identify a spell being cast. |
| [[Dismiss Spell]]  | [[Free Action]]                         | End one spell you control.                                   |

| Movement Action | Duration        | Description                                                                                                |
| --------------- | --------------- | ---------------------------------------------------------------------------------------------------------- |
| [[Dash]]        | [[Double Action]]   | Move up to your [[Walking Speed]].                                                                         |
| [[Hide]]        | [[Double Action]]   | Make a [[Stealth]] [[Check]] to become hidden.                                                             |
| [[Escape]]      | [[Double Action]]   | Make an [[Acrobatics]] or [[Athletics]] [[Check]] to end [[Grappled]], [[Restrained]], or [[Immobilized]]. |
| [[Stand Up]]    | [[Action]]      | Stand up from being [[Prone]].                                                                             |
| [[Drop Prone]]  | [[Free Action]] | Fall [[Prone]].                                                                                            |

| Misc Action        | Duration      | Description                                                      |
| ------------------ | ------------- | ---------------------------------------------------------------- |
| [[Drink Potion]] | [[Action]]    | Drink a potion.                                                  |
| [[Deliver Potion]] | [[Double Action]] | Administer a potion to another creature.                         |
| [[First Aid]]      | [[Double Action]] | Make a [[Medicine]] [[Check]] to stabilize a [[Dying]] creature. |
| [[Seek]]           | [[Action]]    | Make a [[Perception]] [[Check]] to search the area.              |
| [[Use Object]]     | [[Double Action]] | Interact with or activate an object.                             |
| [[Pick Lock]]    | [[Triple Action]] | Make a [[Lockpicking]] [[Check]] to open a lock.                 |
| [[Disarm Trap]]    | [[Triple Action]] | Make a [[Lockpicking]] [[Check]] to disable a trap.              |
