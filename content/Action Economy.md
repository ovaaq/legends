## Action Economy

In one [[Encounter Turn]] you have

- 3 Actions
- Movement
- Reaction
- Free Action

You can use your Actions in any of the combination

- [[Action]] + [[Action]] + [[Action]]
- [[Double Action]] + [[Action]]
- [[Triple Action]]

| Action Symbol |       Name        |
| :-----------: | :---------------: |
|       ▶       |    [[Action]]     |
|      ▶▶       | [[Double Action]] |
|      ▶▶▶      | [[Triple Action]] |
