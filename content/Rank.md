Ranks represent a character’s level of training in a specific [[Skill]] or [[Saving Throw]]. Each Rank grants a +1 bonus to related [[Check|Checks]]. Ranks range from 0 to 8.

| Rank | Modifier |                            Description                             |
| :--: | :------: | :----------------------------------------------------------------: |
|  0   |    +0    |    **Untrained.** You have no additional knowledge or training.    |
|  1   |    +1    |                                                                    |
|  2   |    +2    |                                                                    |
|  3   |    +3    |                                                                    |
|  4   |    +4    |                       etc something between                        |
|  5   |    +5    |                                                                    |
|  6   |    +6    |                                                                    |
|  7   |    +7    |                                                                    |
|  8   |    +8    | **Grand Master.** You are one of the best with strongest training. |
