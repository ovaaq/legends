You have 40 points to spend on your [[Attribute|Attributes]]. The cost of each [[Attribute]] is shown in the [[Attribute|Attributes]] point cost table. For example, a [[Attribute]] of +3 costs 8 points. Using this method, the highest [[Attribute]] you can start with is +4, and no [[Attribute]] can be reduced below −3.

| Attribute | Cost |
| :-------: | :--: |
|    -3     |  0   |
|    -2     |  1   |
|    -1     |  2   |
|     0     |  3   |
|    +1     |  4   |
|    +2     |  6   |
|    +3     |  8   |
|    +4     |  11  |
