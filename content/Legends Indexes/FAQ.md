#### What makes Legends 1e special?

Legends 1e is fully classless ttrpg! It provides framework to create unique character with Talent Tree architecture. It is quite classical D\&D like game, but it has been modified somewhat. D\&D 5e is big source of inspiration and also some things that I have been wanting to fix. This game is also metric!

#### What do I need to play?

d20, d12, d10, d8, d6 and d4. There is PDF-files which you can print freely. See [[Character Sheet]].

#### How to play X class in Legends?

In legends you are not limited to class thinking, but if you enjoy certain archetype you can read more about [[Building Archetypes]] page.

#### How crunchy is the game?

I would say Legends 1e is between D\&D 5e and Pathfinder 2e. Characters can be multi resource and logical puzzles if you want it, but it is not a must.
